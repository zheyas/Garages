# Garages

Приложение для объединения и анализа данных по аренде гаражей и банковским выпискам. Позволяет:
- Загружать Excel-файл с данными аренды (.xlsx)
- Загружать банковскую выписку по операциям (.xlsx)
- Нормализовать названия колонок и типы данных
- Объединять информацию и формировать сводный отчёт
- Просматривать результаты в виде таблицы и столбчатой диаграммы статусов

## Требования

- Python 3.8 или выше  
- Модули (см. requirements.txt):  
  - pandas  
  - openpyxl  
  - matplotlib  
  - tk (входит в стандартную библиотеку Python)

## Установка

1. Клонируйте репозиторий:
```
git clone https://github.com/zheyas/Garages.git
cd Garages
```
2. (Рекомендуется) Создайте виртуальное окружение и активируйте его:

```
   python3 -m venv .venv
   source .venv/bin/activate      # macOS/Linux
   .venv\Scripts\activate         # Windows
```   
3. Установите зависимости:
```
   pip install -r requirements.txt
```


## Запуск

После установки зависимостей выполните:
```
python main.py
```
Откроется графический интерфейс Tkinter.



## Использование

1. Нажмите «Загрузить аренду» и выберите Excel-файл с данными по аренде гаражей.  
2. Нажмите «Загрузить выписку» и выберите банковскую выписку (.xlsx).  
3. После успешной загрузки появится кнопка «Показать отчёт».  
4. В новом окне отобразится таблица с объединёнными данными и кнопка «График».  
5. Нажмите «График» для отображения столбчатой диаграммы: количество гаражей в статусах  
   (Получен, Просрочен, Срок не наступил).



## Формат входных файлов

### Файл аренды (arenda.xlsx)
Должны быть столбцы (имена могут отличаться, но будут автоматически нормализованы):
- Дата начала аренды  
- Дата окончания аренды  
- Номер гаража  
- Стоимость аренды и т.д.  

### Банковская выписка (vypiska.xlsx)
Должны быть столбцы:
- Дата операции  
- Сумма  
- Описание операции  
- Категория  

Обратите внимание, что любые дополнительные символы в суммах (+, пробелы, запятые) корректно обрабатываются функцией normalize_sum.
